FAQ: using SafePhone

What permissions does SafePhone need on my phone?

To block calls, SafePhone needs Android's Call Screening permission. To check and block links, you set SafePhone as your default browser. You only need to grant permissions for the features you actually use.

Which SafePhone feature should I start with?

For elderly parents, start by blocking calls from numbers not in their contacts and turning on unknown-call alerts. For children, turn on scam website blocking or allow only trusted websites. For everyday users, blocking unknown numbers and checking links is enough.

Do I have to use Slack to receive alerts?

No. Call blocking, website blocking and ad blocking all work independently. You only need a Slack channel if you want to be alerted when a family member receives a call from an unknown number or taps a suspicious link.
