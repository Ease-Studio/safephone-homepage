How to create OpenAI and DeepSeek API keys to add AI to SafePhone

SafePhone · Updated September 27, 2026

SafePhone can connect to AI to get the most out of its fake-content detection. To turn this on, you need to create an OpenAI API key or a DeepSeek API key — an authentication code that lets the app talk to the AI service. This guide walks you step by step through how to create an OpenAI API key and a DeepSeek key, add credit, keep your key safe and enter it in SafePhone.

What is an API key and why does SafePhone need one?

Modern AI models such as those from OpenAI and DeepSeek let developers build artificial intelligence into apps, websites and automated systems through an API. To use these services, you need to create an API key — an authentication code that lets your app communicate with the AI service.

Once you enter an API key in SafePhone, the app can use AI to improve its detection of fake content, on top of its built-in blacklist matching (see how SafePhone works). The AI feature is optional: features such as how to block unknown and scam numbers automatically and how to check if a website is a scam still work without AI turned on.

How to create an OpenAI API key

OpenAI's official site: https://platform.openai.com/

Step 1: Sign up or sign in to OpenAI

Go to OpenAI's developer platform at https://platform.openai.com/. Sign in, or create a new account if you don't have an OpenAI account yet.

Step 2: Open the API keys section

  1. Click API keys in the left-hand menu.
  2. Click + Create new secret key; a dialog box will appear.

Step 3: Create a new API key

  1. In the dialog, give the key a name in the Name field (any name works, e.g. SafePhone AI).
  2. Click Create secret key; another dialog will appear.
  3. This dialog shows the API key you need to save. Copy it and store it somewhere safe so you can paste it into the SafePhone app.
Note: an API key is like a password — never share it with anyone.

Step 4: Set up billing

To use an OpenAI API key, you need a valid payment method or a credit balance on your account. To add credit:

  1. Go to the Billing page: https://platform.openai.com/settings/organization/billing/overview
  2. Check OpenAI's pricing at https://openai.com/api/pricing/
  3. Click Add payment details, enter your payment information and pay as usual.

How to create a DeepSeek API key

DeepSeek's official site: https://platform.deepseek.com/

Step 1: Sign up or sign in to DeepSeek

Go to DeepSeek's developer platform at https://platform.deepseek.com/. Sign in, or create a new account if you don't have a DeepSeek account yet.

Step 2: Open the API keys section

  1. Click API keys in the left-hand menu.
  2. Click Create new API key; a dialog box will appear.

Step 3: Create a new API key

  1. In the dialog, give the key a name in the Name field (any name works, e.g. SafePhone AI).
  2. Click Create API key; another dialog will appear.
  3. This dialog shows the API key you need to save. Copy it and store it somewhere safe so you can paste it into the SafePhone app.
Note: an API key is like a password — never share it with anyone.

Step 4: Set up billing

To use a DeepSeek API key, you need a valid payment method or a credit balance on your account. To add credit:

  1. Go to DeepSeek's Top-up page: https://platform.deepseek.com/top_up
  2. Check DeepSeek's pricing at https://api-docs.deepseek.com/quick_start/pricing/
  3. Enter your payment information and pay as usual.

Keeping your API key secure

An API key is like the password to your AI account. If it leaks, someone else can use your account and run up charges you didn't expect. Here are some ways to store a newly created key:

  • Create a Word file on your computer, paste the API key into it, and keep the file somewhere safe or protect it with a password.
  • Create a file in your Google Drive, save the API key there and set it so only you can view it.
  • Check your API key usage regularly at https://platform.openai.com/usage (OpenAI) or https://platform.deepseek.com/usage (DeepSeek). If you notice anything unusual, delete that key and create a new one.
Watch out for scams: never send your API key by text message, on social media, or to anyone claiming to be “tech support”. Scammers often pose as support staff to ask for passwords and OTP codes — your API key deserves the same protection. See also habits that leak your personal data.

Entering your API key in SafePhone

Once you've created an API key, enter it in the API Key field in SafePhone:

  1. Open the SafePhone app. Don't have it yet? Get it on Google Play.
  2. Tap the AI button right next to the “SafePhone” title; a dialog will appear.
  3. Tap Activate AI (“kích hoạt AI”).
  4. Choose your AI provider: OpenAI or DeepSeek (whichever you created the key with).
  5. Paste the key into the API Key field.
  6. Tap Save (“Lưu lại”).

When you're done, the AI button turns green.

Conclusion

In just a few steps — signing in to the developer platform, creating a key, adding credit and pasting the key into SafePhone — you can turn on AI to improve fake-content detection. Treat your API key like a password and check your usage regularly to avoid unexpected charges.

FAQ

Do I need an API key to use SafePhone?

No. You only need an API key if you want to turn on the AI feature. Call blocking, scam website blocking and ad blocking all work without AI.

Should I choose OpenAI or DeepSeek?

SafePhone supports both, and you only need a key from one provider. Compare OpenAI's and DeepSeek's pricing to choose the option that suits your needs.

Does using an OpenAI or DeepSeek API key cost money?

Yes. To use an API key you need a valid payment method or a credit balance on your account; charges follow the provider's price list.

What should I do if my API key leaks?

Delete that key right away on the OpenAI or DeepSeek platform, create a new key and enter it in SafePhone again. Then check the Usage page for any unusual activity.

How do I know SafePhone is connected to AI?

After you paste your API key and tap Save, the AI button next to the SafePhone title turns green.
