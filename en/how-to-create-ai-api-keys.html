API key là gì và vì sao SafePhone cần?

Các mô hình AI hiện đại như OpenAI và DeepSeek cho phép nhà phát triển tích hợp trí tuệ nhân tạo vào ứng dụng, website hoặc hệ thống tự động hoá thông qua API. Để sử dụng các dịch vụ này, bạn cần tạo một API key — mã xác thực giúp ứng dụng của bạn giao tiếp với hệ thống AI.

Khi bạn nhập API key vào SafePhone, ứng dụng có thể dùng AI để tăng khả năng phát hiện nội dung giả mạo, bên cạnh cơ chế đối chiếu danh sách đen sẵn có (xem SafePhone hoạt động như thế nào). Tính năng AI là tuỳ chọn: các tính năng như cách chặn số lạ, số lừa đảo tự động hay kiểm tra trang web lừa đảo vẫn hoạt động khi bạn chưa bật AI.

Bạn cần chuẩn bị gì?

  • Một địa chỉ email (hoặc tài khoản Google) để đăng ký.
  • Một máy tính có trình duyệt — các trang quản lý API dễ thao tác trên máy tính hơn.
  • Thẻ thanh toán quốc tế (Visa/Mastercard) hoặc phương thức thanh toán mà nhà cung cấp chấp nhận. Dùng API là dịch vụ trả phí theo mức sử dụng.

Thứ tự nên làm: đăng ký tài khoản → nạp tiền → tạo API key → dán key vào SafePhone. Nạp tiền trước giúp key hoạt động ngay khi bạn nhập vào ứng dụng.

Phần A: Tạo API key OpenAI từ đầu

Bước A1: Đăng ký tài khoản OpenAI

  1. Mở platform.openai.com trên máy tính và bấm Sign up (đã có tài khoản ChatGPT thì bấm Log in và dùng luôn tài khoản đó).
  2. Nhập email rồi bấm Continue, hoặc chọn đăng nhập bằng Google.
  3. Đặt mật khẩu, mở hộp thư và bấm vào link xác nhận OpenAI gửi tới.
  4. Điền thông tin cơ bản theo hướng dẫn trên màn hình (tên, ngày sinh). OpenAI có thể yêu cầu xác minh số điện thoại.

Bước A2: Nạp tiền vào tài khoản

  1. Mở trang Billing (hoặc bấm biểu tượng bánh răng Settings → Billing).
  2. Bấm Add payment details, chọn dùng cá nhân (Individual) và nhập thông tin thẻ.
  3. Chọn số tiền nạp — mức tối thiểu là $5, thường đủ để bắt đầu.
  4. OpenAI bật sẵn chế độ tự động nạp thêm tiền (auto recharge). Nếu muốn kiểm soát chi phí, hãy tắt tuỳ chọn này trước khi xác nhận.
  5. Bấm xác nhận để hoàn tất. Xem bảng giá tại openai.com/api/pricing.

Bước A3: Tạo API key

  1. Mở trang API keys (hoặc chọn API keys ở menu bên trái).
  2. Bấm + Create new secret key.
  3. Ở ô Name, đặt tên dễ nhớ, ví dụ SafePhone, rồi bấm Create secret key.
  4. Bấm Copy để sao chép key (bắt đầu bằng sk-) và lưu ở nơi an toàn.
Quan trọng: OpenAI chỉ hiển thị key một lần. Nếu đóng hộp thoại mà chưa sao chép, bạn phải tạo key mới.

Phần B: Tạo API key DeepSeek từ đầu

Bước B1: Đăng ký tài khoản DeepSeek

  1. Mở platform.deepseek.com và chọn đăng ký (Sign up).
  2. Đăng ký bằng email (nhập mã xác nhận được gửi về hộp thư) hoặc đăng nhập bằng Google.
  3. Đăng nhập vào trang quản lý sau khi tạo tài khoản.

Bước B2: Nạp tiền vào tài khoản

  1. Mở trang Top up (hoặc mục Top up ở menu bên trái).
  2. Chọn số tiền muốn nạp và một phương thức thanh toán có sẵn trên trang, rồi hoàn tất thanh toán.
  3. Xem bảng giá tại api-docs.deepseek.com/quick_start/pricing.

Bước B3: Tạo API key

  1. Mở trang API keys.
  2. Bấm Create new API key, đặt tên, ví dụ SafePhone, rồi bấm Create.
  3. Sao chép key (bắt đầu bằng sk-) và lưu ở nơi an toàn — key cũng chỉ hiển thị một lần.

Phần C: Nhập API key vào SafePhone

Sau khi tạo API key thành công, bạn nhập key vào ô API Key trong SafePhone:

  1. Mở ứng dụng SafePhone. Chưa cài? Tải trên Google Play.
  2. Bấm vào nút có chữ AI ngay bên cạnh tiêu đề “SafePhone”; một hộp thoại sẽ hiện lên.
  3. Bấm kích hoạt AI.
  4. Chọn nhà cung cấp AI: OpenAI hoặc DeepSeek (đúng với nơi bạn đã tạo key).
  5. Dán API key vào ô API Key.
  6. Bấm Lưu lại.

Sau khi hoàn tất, nút có chữ AI sẽ chuyển sang màu xanh.

Giữ API key an toàn và kiểm soát chi phí

API key giống như mật khẩu của dịch vụ AI. Nếu bị lộ, người khác có thể dùng tài khoản của bạn và phát sinh chi phí ngoài ý muốn. Bạn có thể lưu API key vừa tạo theo các cách sau:

  • Lưu key trong trình quản lý mật khẩu, hoặc một file chỉ mình bạn truy cập được.
  • Với OpenAI, tắt auto recharge và chỉ nạp số tiền nhỏ để giới hạn chi phí tối đa.
  • Thường xuyên kiểm tra mức sử dụng của API key tại https://platform.openai.com/usage (OpenAI) hoặc https://platform.deepseek.com/usage (DeepSeek). Nếu thấy bất thường, hãy xoá API key đó và tạo key mới.
Cảnh giác lừa đảo: không gửi API key qua tin nhắn, mạng xã hội hay cho người tự xưng là “hỗ trợ kỹ thuật”. Kẻ gian thường giả danh bộ phận hỗ trợ để xin mật khẩu, mã OTP — API key cũng cần được bảo vệ như vậy. Xem thêm thói quen làm lộ dữ liệu cá nhân.

Kết luận

Chỉ với vài bước — đăng nhập trang dành cho nhà phát triển, tạo key, nạp tiền và dán key vào SafePhone — bạn đã bật được tính năng AI để tăng khả năng phát hiện nội dung giả mạo. Hãy giữ API key như mật khẩu và thường xuyên kiểm tra mức sử dụng để tránh chi phí ngoài ý muốn.

Câu hỏi thường gặp

Có bắt buộc tạo API key để dùng SafePhone không?

Không. API key chỉ cần khi bạn muốn bật tính năng AI. Các tính năng chặn cuộc gọi, chặn web lừa đảo và chặn quảng cáo vẫn hoạt động khi chưa bật AI.

Nên chọn OpenAI hay DeepSeek?

SafePhone hỗ trợ cả hai, bạn chỉ cần tạo key ở một nhà cung cấp. Hãy tham khảo bảng giá của OpenAI và DeepSeek để chọn phương án phù hợp với nhu cầu.

Dùng API key OpenAI hoặc DeepSeek có mất phí không?

Có. Để sử dụng API key, bạn cần có phương thức thanh toán hợp lệ hoặc số dư trong tài khoản; chi phí tính theo bảng giá của nhà cung cấp.

Cần nạp bao nhiêu tiền để bắt đầu?

Với OpenAI, mức nạp tối thiểu là 5 USD. Với DeepSeek, hãy xem số tiền tối thiểu hiển thị trên trang Top up. Bạn có thể bắt đầu với số tiền nhỏ và theo dõi trang Usage.

Lỡ để lộ API key thì phải làm gì?

Hãy xoá ngay API key đó trên trang quản lý của OpenAI hoặc DeepSeek, tạo key mới và nhập lại vào SafePhone. Sau đó kiểm tra trang Usage để phát hiện mức sử dụng bất thường.

Làm sao biết SafePhone đã kết nối AI thành công?

Sau khi dán API key và bấm Lưu lại, nút có chữ AI bên cạnh tiêu đề SafePhone sẽ chuyển sang màu xanh.
